# Obrázky do mailů (Outlaws Digital)

Veřejný hosting obrázků, které jsou v odeslaných e-mailech klientů (Ecomail). Servíruje se přes GitHub Pages:
`https://outlaws-digital.github.io/mail-obrazky/<klient>/<RRRR-MM>/<soubor>`

**Repo nemazat, nepřejmenovávat a soubory nepřepisovat.** Odeslané maily na ně odkazují natrvalo.
Nová verze obrázku = nový název nebo nová složka měsíce.

Sem patří jen obrázky, které jdou ven v mailech. Nic jiného (zdroje, fonty, data klientů jsou v private repu `outlaws`).
